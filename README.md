# Cozy Village AFK

A small Canvas-based fishing and idle game that runs in a Visual Studio Code WebView.

## Development

```powershell
npm.cmd install
npm.cmd run check
npm.cmd test
npm.cmd run compile
```

Press `F5` from this folder, then run **Cozy Village: Open Game** in the Extension Development Host.

Build an installable package with `npm.cmd run package:vsix`. Versioned packages are written to `releases/`.
